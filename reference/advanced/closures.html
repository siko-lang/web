Closures & Captures

Closures are anonymous functions that can capture variables from the surrounding scope. In Siko they are written with |args| syntax and the argument types are always inferred.

Basic Syntax

let double = |x| x * 2;
let add    = |x, y| x + y;

A closure with a body block:

let greet = |name| {
    let msg = "Hello, ${name}!";
    println(msg);
};

Captures

A closure captures variables from its enclosing scope by reference. Mutations inside the closure are visible outside:

let count = 0;
let inc = || { count = count + 1; };
inc();
inc();
// count is now 2

Closures as Arguments

The most common use is passing closures to higher-order functions:

let nums = [1, 2, 3, 4, 5];
let evens = nums.iter().filter(|x| x % 2 == 0).collect();
let doubled = nums.iter().map(|x| x * 2).collect();

Returning Closures

A function can return a closure. The return type uses the fn type:

fn make_adder(n: Int) -> fn(Int) -> Int {
    |x| x + n
}

let add5 = make_adder(5);
let result = add5(3);   // 8

Closures and Effects

Closures inherit the effect context of their enclosing scope. A closure defined inside a with block can call effect methods directly:

with log = console_log {
    let action = || Logger.log("from closure");
    action();   // dispatches to console_log
}
